# Roadmap and review entry point

This is a dependency-ordered plan, not a delivery-date commitment.

1. Read [current-state evidence](current-state.md).
2. Resolve [open questions](open-questions.md) and review proposed ADRs.
3. Work through [milestones](milestones.md) as vertical slices.
4. Maintain the [delivery checklist](checklist.md) with source/test evidence.

Do not mark a platform feature done because its Cargo package exists or a design
system example renders it. Work not listed as implemented remains planned.
